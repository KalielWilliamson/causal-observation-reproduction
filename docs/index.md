# Sequential Causal-Observation Benchmark

This repository is the public reproduction boundary for the COO algorithm, its
formal foundations, and every paper-visible experiment. Start with the
[paper experiment inventory](paper_experiment_inventory.md), then use the
[reproduction boundary](reproduction.md),
[benchmark contract](benchmark_contract.md), and
[experiment guide](experiments.md).

The canonical commands execute a pinned extraction of the implementation used by
the manuscript and fail closed against the reported finite-grid values. The
inventory distinguishes the exact one-step, sequential, and MiniGrid evidence
from a separately labelled family of post-manuscript extensions.
